# Signed SOW — RetailCo Returns Portal

Doc type: SIGNED_SOW
Origin: joint
Status: signed
Recency date: 2026-03-18

## Scope
- Returns portal for Shopify Plus customers.
- NetSuite RMA creation.
- Shopify replacement orders after warehouse receipt for exchanges.
- Zendesk return status visibility.
- Finance approval workflow for refunds greater than $500.

## Out of Scope
- Returns for in-store purchases.
- Loyalty point adjustments.
- International returns.
- Automated refund issuance before Finance approval.

## Dates
- UAT start: 2026-05-05
- UAT complete: 2026-05-16
- Go-live: 2026-05-27

## Responsibilities
- Auctor owns test environment setup.
- RetailCo owns UAT execution.
- RetailCo Finance owns refund approval test users.
