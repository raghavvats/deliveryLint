# Approved Change Order — Labor Reporting Dashboard

Doc type: CHANGE_ORDER
Origin: joint
Status: approved
Recency date: 2026-03-02

## Approved Scope
- Add read-only labor reporting dashboard using existing Manhattan WMS event data.
- Dashboard includes picks per hour, cartons packed per hour, and supervisor-level daily totals.

## Out of Scope
- Labor optimization recommendations.
- Shift scheduling.
- Incentive compensation calculations.

## Timeline Impact
- UAT complete moves from 2026-04-17 to 2026-04-22.
- Go-live moves from 2026-04-29 to 2026-05-06.

## Responsibilities
- Auctor owns dashboard configuration.
- GlobalFoods owns validation of dashboard metrics.

## Assumptions and Dependencies
- Existing WMS event data is sufficient; no additional scanner hardware is required.
