## Scope Covered by Plan
This project plan covers cardiology, orthopedics, and oncology prior authorization workflows. Auctor will configure rules and replacement Epic workqueues so authorization teams can work efficiently.

## Responsibilities
Auctor will coordinate Epic analyst access, HIPAA review, ClearingHub test files, rules engine configuration, dashboard development, testing, and training.
ValleyCare will provide input as needed.

## Dependencies
- Epic access should be available before configuration starts.
- HIPAA review should be done before go-live.
- ClearingHub file should arrive soon.

## Risks
The project is expected to remain on track. Minor dependency delays can be absorbed without timeline impact.
