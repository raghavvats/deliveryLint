# Signed SOW — ValleyCare Prior Authorization Workflow

Doc type: SIGNED_SOW
Origin: joint
Status: signed
Recency date: 2026-02-14

## Scope
- Configure prior authorization workqueue in Epic for cardiology and orthopedics.
- Integrate payer eligibility response file from ClearingHub into the authorization rules engine.
- Build coder review dashboard for prior authorization mismatches.
- Create Epic In Basket notification for cases requiring manual review.
- Train up to 20 coder and scheduling users.

## Out of Scope
- Oncology workflows.
- Replacing Epic workqueues.
- Automated payer submission.
- Patient-facing portal changes.
- Real-time payer API integration.
